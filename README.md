# Pacific Front 自动排阵与游玩 · 使用说明

## 一、安装油猴脚本管理器（Tampermonkey）

Tampermonkey（中文常叫“油猴”或“篡改猴”）是一个浏览器扩展，本身不提供功能，只负责管理和运行 `.user.js` 脚本。

### Edge 浏览器（推荐，国内网络无障碍）

Edge 是 Windows 自带浏览器，安装 Tampermonkey 最省事。

1. 打开 Edge，点击右上角 `⋯` → **扩展** → **获取 Microsoft Edge 扩展**。
2. 在商店搜索框输入 **Tampermonkey**（中文“篡改猴”），认准官方结果（图标是两个小方块）。
3. 点击 **获取** → **添加扩展**，安装完成后右上角会出现油猴图标。点击图标并选择 **固定到工具栏**，方便后续操作。

### Chrome 浏览器

Chrome 网上应用店在国内可能无法直接访问。可尝试以下方式：

- 在 Chrome 地址栏打开 `chrome://extensions/`，开启右上角 **开发者模式**，将从 [Tampermonkey 官网](https://www.tampermonkey.net/) 或其他可信来源下载的 `.crx` 文件直接拖入扩展页面完成安装。
- 或使用 **Crx 搜搜扩展商店** 等第三方镜像搜索 Tampermonkey 进行安装（注意甄别来源，不建议随意下载不明 `.crx` 文件）。

### 其他浏览器

Firefox、Opera、360 等浏览器的安装逻辑类似：进入扩展/附加组件页面，搜索 Tampermonkey，或拖入 `.crx` / `.xpi` 文件安装。

## 二、安装本脚本

脚本管理器装好后，把 `.user.js` 内容导入即可。**推荐方式 A（手动粘贴）**，最适合当前这种尚未发布到公共脚本库的脚本。

### 方式 A：手动新建脚本（推荐）

1. 点击浏览器工具栏的 Tampermonkey 图标 → **管理面板**（仪表盘）。
2. 点击 **+** 或 **添加新脚本**，编辑器会打开一个默认模板。
3. **删除编辑器中全部默认内容**，把完整的 `Pacific Front 自动排阵与游玩.user.js` 代码粘贴进去。注意必须保留顶部的 `// ==UserScript== ... // ==/UserScript==` 元信息块，不能删除。
4. 按 `Ctrl + S`（Mac 为 `Cmd + S`）保存。在管理面板中确认该脚本前面的复选框已勾选（启用状态）。

### 方式 B：拖入文件

如果已有 `.user.js` 文件，也可以直接将其拖入 Tampermonkey 管理面板，或拖入浏览器扩展页面，按提示安装。

### 安装后自检

1. 打开 Pacific Front 游戏页面（如 `pacificfront.worldofwarships.asia`）。
2. 按 `F12` 打开开发者工具 → **Console**，应能看到 `[PacificFrontBot] v1.9.3 已加载…` 之类的日志。
3. 页面右上角会出现一个悬浮控制面板，包含“仅预览 / 自动选卡 / 自动游玩 / 停止”按钮。

如果 Console 报 **“页面版本不匹配”**，说明游戏更新了，脚本里的 `ENGINE_VERSION` 需要更新为新的构建哈希。报错信息会直接给出当前页面的哈希（例如 `f8656594`），将其填入脚本开头的 `ENGINE_VERSION` 常量，保存后刷新游戏页面即可。

## 三、脚本实现逻辑（简略）

脚本的核心思路是：**不自己实现战斗计算，而是调用游戏页面已有的预测引擎，把“选哪 4 张卡、配哪些增益品”当作搜索问题，在合法组合空间里找胜率最高的方案，再通过官方接口提交战斗。**

### 1. 识别当前状态

通过游戏页面的公开接口（`/api/v2/state/`、`/api/v2/operation/{id}/`、`/api/v2/inventory/` 等）读取当前行动、阶段、节点、库存和可用卡牌。同时从 `window.settings`、`window.adeck`、`window.defaultState` 这些页面全局对象拿到预测引擎和配置。

### 2. 筛选可用卡牌

根据当前阶段的已出战记录、卡牌生命值、战斗条件（effects）的限制规则，筛掉不能用的卡。战斗条件包括增伤、减益、禁用增益品、额外限制等，脚本会逐条解析并应用到预测板上。

### 3. 桥接页面预测引擎

脚本不重写胜率算法，而是调用页面已有的 `window.adeck.predict`。它负责构造预测所需的“棋盘”（敌方 4 格、我方 4 格、增益品、战斗条件），然后从引擎返回的 `Predictions` 中读出每个位置的胜率。

### 4. 搜索最优阵容

这是脚本最耗时的部分。由于 4 个槽位、每张卡还可能配 1~2 个增益品，组合空间很大，脚本采用**分层搜索**：

- **坐标搜索 + 换位**：从多个起点出发，反复尝试“在某个位置换一张卡（并可同时换增益品组合）”，接受评分更高的方案；再尝试两卡互换（连同增益品重新分配）。不保证全局最优，但通常能快速找到高质量解。
- **联合搜索**：把“卡牌 + 增益品”放在一起评估，而不是先定卡再配增益品，以免错过“某张卡必须配某个绿色增益品才能触发减益”这类联动。
- **无限制穷举（兜底）**：如果常规搜索后仍有槽位低于选卡底线（默认 80%），脚本会切换到完整枚举，检查当前库存下所有合法的卡牌组合与增益品分配。这一步可能很慢，但可以保证“如果存在满足底线的方案，就一定能找到”。

评分规则大致是：先看是否所有槽位都达到选卡底线 → 再看是否填满 4 槽 → 再看是否所有槽位都达到开战底线（默认 90%）→ 再看最弱槽位的胜率 → 再看优化目标（默认 100%）的差距 → 最后才比较总击败数等指标。增益品在“胜率不变差”的前提下会尽量少用。

### 5. 复核与提交

搜索出的方案不会直接提交。脚本会重新读取服务端最新的行动、库存和节点状态，用当前数据重新跑一遍预测，确认卡牌仍可用、增益品仍有库存、胜率仍达标。只有复核通过，才通过官方接口提交战斗。

### 6. 三种运行模式

- **仅预览**：只搜索并打印方案，不提交战斗，适合先看脚本会怎么选。
- **自动选卡**：把搜索到的卡牌和增益品填入页面卡槽，但不提交战斗，适合手动确认或微调。
- **自动游玩**：选卡 → 复核 → 提交战斗 → 等待结算 → 根据阶段目标决定进入下一阶段或结束行动，循环执行直到达到战斗上限或行动完成。

## 四、使用提示

- 第一次使用建议先点 **“仅预览”**，确认脚本能正常读取游戏状态并给出合理阵容，再尝试“自动选卡”或“自动游玩”。
- 脚本依赖页面的预测引擎，**游戏大版本更新后可能需要同步更新 `ENGINE_VERSION`**；报错信息会给出新哈希，按提示修改即可。
- 脚本通过 `navigator.locks` 保证同一浏览器同一时间只有一个标签页在运行，避免重复提交战斗。
- 如果需要调整开战底线、选卡底线、优化目标、是否自动购买增益品等，可以修改脚本顶部的 `defaults` 对象。
